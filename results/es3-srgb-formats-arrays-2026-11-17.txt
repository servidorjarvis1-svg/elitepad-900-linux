## dev bugs found on the way (both fixed on the branch)

- lower_srgb_filter built each tap's coordinate after inserting the tap: a 2D sRGB texture
  filtered LINEAR in the shader failed to compile ("unsupported instruction type 1") and the
  draw was skipped. Probe: an sRGB texture LINEAR halfway between 0 and 255 from a varying.
    dev:    0 0 0 0   (nothing drawn)
    fixed:  131 131 131 255   (linear 0.5 = 128, at the pixel's offset)
- txf_to_txl built an array texelFetch's coordinate as vec2(uv, layer) with uv a vector:
  invalid NIR, nir_opt_copy_prop crashed in sgx_lower at link time (gdb backtrace on the tablet).

## Known limits

- Float textures are F32 planes, strided, one level: a mipmapped float texture samples its
  base level (sgx_es3fmt test 9, informative). A twiddled 0x12 with mips is an untested H2 case.
- Shader LINEAR filtering of F32 / sRGB textures is at one level (as on dev for sRGB).
- glBlendColor is part of an sRGB blend variant's key: animating it recompiles.
